# Investigating the Bias–Variance Trade-off in Polynomial Regression

An experimental study exploring how model complexity, training dataset size, observation noise, and L2 regularisation influence the generalisation performance of polynomial regression models.

## Overview

The bias–variance trade-off is a fundamental concept in machine learning that describes the relationship between a model's complexity, its ability to fit training data, and its ability to generalise to unseen observations.

The objective of this project is to investigate this relationship through controlled experiments using polynomial regression.

Rather than relying exclusively on theoretical explanations, this study examines how different modelling choices influence predictive performance through repeated simulations and empirical analysis.

## Research Objectives

The primary objectives of this study are:

- Investigate the relationship between polynomial degree and generalisation performance.
- Examine how training dataset size influences model behaviour.
- Understand the relationship between squared bias and variance.
- Analyse the effect of L2 regularisation on model complexity.
- Investigate how observation noise interacts with model complexity and regularisation.
- Examine the relationship between training error and evaluation error.

## Experimental Setup

The experiments use a synthetic data-generating process based on the following underlying function:

\[
f(x) = \sin(1.5\pi x)
\]

Observations are generated by adding Gaussian noise:

\[
y = f(x) + \epsilon
\]

where:

\[
\epsilon \sim \mathcal{N}(0,\sigma^2)
\]

The experiments systematically vary:

| Parameter | Values |
|---|---|
| Polynomial degrees | 3, 5, 10, 15 |
| Training dataset sizes | 10, 20, 50, 100, 250, 500 |
| Noise levels | 0.05, 0.1, 0.2, 0.4, 0.6 |
| Regularisation strengths | 0, 0.0001, 0.001, 0.01, 0.1, 1, 10 |

Repeated simulations are used to analyse model performance and estimate squared bias and variance.

## Experiments

The current study consists of seven major experiments:

1. **Model Complexity vs. Training Dataset Size**  
   Investigating how polynomial degree and the amount of training data influence generalisation performance.

2. **Bias–Variance Analysis**  
   Examining how squared bias and variance contribute to predictive error across different model complexities and training dataset sizes.

3. **Effect of L2 Regularisation**  
   Investigating how different regularisation strengths influence model performance and the bias–variance trade-off.

4. **Training Dataset Size vs. Optimal Regularisation**  
   Exploring how the preferred regularisation strength changes with the amount of available training data.

5. **Polynomial Degree vs. Optimal Regularisation**  
   Examining how model complexity influences the effectiveness of regularisation.

6. **Observation Noise vs. Optimal Regularisation**  
   Investigating how different noise levels affect the regularisation strength required for better generalisation.

7. **Interaction Between Model Complexity, Noise and Regularisation**  
   Studying how these three factors interact and influence predictive performance.

## Key Findings

The experiments demonstrate several important relationships:

- Increasing model complexity does not necessarily improve generalisation.
- High-degree polynomial models can become unstable when training data are limited.
- Increasing the training dataset size generally improves generalisation.
- Moderate L2 regularisation can significantly reduce variance.
- Excessive regularisation can introduce high bias and lead to underfitting.
- The effectiveness of regularisation depends on model complexity, dataset size and observation noise.
